RSF Android App - ابتدائی ڈیمو

یہ ایک موبائل فرینڈلی PWA ڈیمو ہے، APK نہیں۔
استعمال:
1) ZIP کھولیں۔
2) index.html براؤزر میں کھول کر ڈیمو دیکھیں۔
3) فون میں انسٹال کرنے کے لیے ویب سائٹ کو HTTPS ہوسٹنگ پر اپ لوڈ کرنا ضروری ہے، پھر Chrome کے مینو سے Install app / Add to Home screen منتخب کریں۔

اہم حدود:
- رجسٹریشن، منظوری، ممبرز اور گروپ پیغامات فی الحال اسی ایک براؤزر/ڈیوائس کے local storage میں محفوظ ہوتے ہیں۔
- مختلف لوگوں کے موبائلز کے درمیان حقیقی چیٹ/ڈیٹا شیئرنگ کے لیے Firebase یا کسی دوسرے محفوظ backend کی configuration درکار ہے۔
- حقیقی ایڈمن سیکیورٹی، OTP، تصاویر اپ لوڈ، فون نمبر کی اجازت، اور صبح 9 بجے سرور سے خودکار پیغام اس ڈیمو میں فعال نہیں۔
- نمونہ ایڈمن پاس کوڈ RSF123 ہے؛ اسے حقیقی سیکیورٹی نہ سمجھیں۔
- آیات اور احادیث خودکار طور پر شامل نہیں کی گئیں تاکہ غیر مصدقہ حوالہ نہ جائے۔
